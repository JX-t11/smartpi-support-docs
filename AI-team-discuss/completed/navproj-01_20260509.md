## Problem

Two .mdx files exist on disk but are **missing from `docs/docs.json`**, making them unreachable through the Mintlify navigation bar. This means users cannot discover these pages from the nav UI — only via direct URL or search.

**Missing pages:**

| File | Title |
|------|-------|
| `reference/chip/ci1302.mdx` | CI1302 芯片技术规格 — BNPU V3 processor for CI-03T, JX-A7T modules |
| `troubleshooting/platform-and-firmware/model-specific.mdx` | Model-specific firmware issues (SU vs CI comparison) |

## Evidence

```bash
# Both files exist on disk:
$ ls docs/reference/chip/ci1302.mdx  # exists
$ ls docs/troubleshooting/platform-and-firmware/model-specific.mdx  # exists

# But neither appears in docs.json "pages" arrays. The only chip entry is reference/chip/index.
# Similarly, model-specific is not listed under the platform-and-firmware group.
```

## Impact

- Users browsing via nav bar will never see CI1302 specs page or model-specific firmware FAQ
- These are critical troubleshooting pages that should be easily discoverable from the nav
- Mintlify validate will report a mismatch between docs.json and filesystem

## Proposed Fix

Add `reference/chip/ci1302` to the "开发参考" group under "案例与参考" tab.

Add `troubleshooting/platform-and-firmware/model-specific` to the "平台与固件" group under "故障排查" tab, after `troubleshooting/platform-and-firmware/model-differences`.

## Files to modify
- `docs/docs.json` — add two page entries to existing groups
