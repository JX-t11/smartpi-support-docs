## Updated Cross-Reference Audit (Round 5)

### Status Update

My previous audit was outdated — most files now have cross-references. The main issues are **broken internal links**, not missing cross-links.

### Broken Link Summary

#### Category 1: Broken Anchor Links (~30 occurrences)
Pages exist but anchors don't match the actual heading text. For example:
- `/modules/offline-voice/su-series#su-32t` → anchor should be `#su-32t——高性能双麦抗噪离线模组` (full heading text, lowercase + hyphenate)
- `/guides/tutorials/index.mdx` has 11 broken anchors to CI/SU series model headings

**Root cause**: Links use simplified anchors like `#ci-03t2` but actual anchors include full Chinese heading text.

#### Category 2: Missing Image Files (~45 occurrences)
Images referenced in markdown but not found on disk:
- `/images/ai-agents/*.png` (6 images, AI agents pages)
- `/images/platform-and-firmware/*.jpg` (18 images, platform config pages)
- `/images/application-scenarios/*.jpg` (9 images, troubleshooting pages)
- `/images/voice-tuning/*.jpg` (4 images)
- `/images/platform-config/*.jpg` (5 images)

#### Category 3: Links to directories without index files (~10 occurrences)
Links like `/guides/hardware-design`, `/troubleshooting/burning-and-debug`, `/modules/offline-voice` that resolve to non-existent pages.

### Implementation Plan

**Phase 1**: Fix broken anchor links in navigation cards and cross-references (highest priority)
**Phase 2**: Address missing image references (requires either adding images or updating links)  
**Phase 3**: Fix directory-level links without index files
